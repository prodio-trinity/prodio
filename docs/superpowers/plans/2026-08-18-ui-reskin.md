# UI 리스킨 (인디고 테마) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 누밋 fork 프론트엔드의 primary 색상을 빨강→인디고로, 사이드바를 따뜻한 브라운→쿨 다크로 교체해 Prodio 고유 디자인을 만든다.

**Architecture:** CSS 토큰 2개 파일(`light.css`, `dark.css`) + 사이드바 모듈 CSS 1개 파일만 수정. 레이아웃·컴포넌트 구조 변경 없음. 모든 컴포넌트는 `var(--color-primary)`를 참조하므로 토큰 교체만으로 전체 반영됨.

**Tech Stack:** CSS Variables, CSS Modules, Next.js

---

### Task 1: 라이트 테마 primary 색상 교체

**Files:**
- Modify: `frontend/features/theme/themes/light.css`

- [ ] **Step 1: `light.css` 수정**

`frontend/features/theme/themes/light.css` 를 아래로 교체:

```css
:root,
:root[data-theme="light"] {
  --color-primary: #5b67d8;
  --color-primary-hover: #4556c8;
  --color-page-background: #f6f4f0;
  --color-content-background: #f7f6f2;
  --color-card-background: #ffffff;
  --color-sidebar-background: #151515;
  --color-border: #e4e0d9;
  --color-text-primary: #111111;
  --color-text-secondary: #817d76;
  --color-success: #3f7d4e;
  --color-danger: #d93d35;
  --color-main-background: var(--color-content-background);
  --color-primary-red: var(--color-primary);
  --color-success-green: var(--color-success);
  --color-warning-red: var(--color-danger);
  --color-dark-background: #151515;
  --background: var(--color-page-background);
  --foreground: var(--color-text-primary);
}
```

- [ ] **Step 2: 로컬 dev 서버에서 시각 확인**

```bash
cd frontend && npm run dev
```

브라우저에서 `http://localhost:3000` 접속 → 로그인 페이지 로고 배지, 사이드바 활성 탭이 인디고로 바뀌었는지 확인.

- [ ] **Step 3: 커밋**

```bash
git add frontend/features/theme/themes/light.css
git commit -m "feat: 라이트 테마 primary 색상 빨강→인디고 교체"
```

### Task 3: 사이드바 따뜻한 브라운 → 쿨 다크 교체

**Files:**
- Modify: `frontend/features/admin/components/AdminSidebar.module.css`

- [ ] **Step 1: 사이드바 배경 및 텍스트 색상 교체**

`AdminSidebar.module.css` 에서 아래 값들을 교체 (6곳):

|---------|---------|------|

| `border-right: 1px solid #2c2a27;` | `border-right: 1px solid #1f2937;` | `.sidebar` |
| `color: #817d76;` | `color: #6b7280;` | `.logoSub` |

| `color: #a8a7a5;` | `color: #9ca3af;` | `.navItem` |
| `color: #a8a7a5;` | `color: #9ca3af;` | `.profileEmail` |

> `.navItem`과 `.toggleButton`의 `#a8a7a5`는 동일 값이라 replace_all 사용 가능. 단 `.logoSub`의 `#817d76`은 별도.
